Excel・スプレッドシートからまとめて登録

すでにExcelやGoogleスプレッドシートで費用（経費）を記録している場合、1件ずつ入力し直す必要はありません。見出し行の項目名を下記に合わせてCSV保存すれば、列の並び順や見出し行の位置（1行目でなくてもOK）に関係なく取り込めます。
対応している列名: 利用日 / 種別（「固定費」「変動費」と入力。無くても費用項目から自動判定します） / 費用項目（Amazon大口手数料・Keepa・その他ツール・梱包費・納品送料・その他費用など） / 詳細/MEMO（メモ・備考でも可） / 金額。
費用項目が上記のいずれとも一致しない場合は「その他ツール」または「その他費用」として取り込み、元の項目名はメモに残します。

1つのシートに「固定費」ブロックと「変動費」ブロックが横に並んでいる場合は、自動判定がうまくいきません。片方のブロックだけを新しいシートにコピーしてCSV保存し、下の「取り込む種別」でそのブロックの種別を指定してから取り込んでください（もう片方のブロックも同様に、もう一度取り込みます）。

Excel・スプレッドシートからまとめて登録

すでにExcelやGoogleスプレッドシートで管理表を作っている場合、1行ずつ入力し直す必要はありません。見出し行の項目名を下記の名前に合わせるだけで、列の並び順はそのままで取り込めます（見出し行が1行目でなく2〜3行目にあっても、自動で見つけて読み込みます）。
① 管理表の見出し行を「対応している列名」に書き換える（すでに近い名前なら不要）
② Excel／スプレッドシートで「ファイル」→「ダウンロード」または「名前を付けて保存」→ 「CSV（カンマ区切り）」形式で保存する
③ 「CSVファイルを選択」ボタンから、保存したファイルを選ぶと自動で取り込まれます

新しく管理表を作る場合は、「CSVテンプレートをダウンロード」した見本ファイルに直接入力してください。

対応している列名（1行目に1つずつ、順不同でOK）:
商品名（品名／商品／タイトルでも可） / 店名（仕入先／仕入れ先／購入先／店舗でも可） / プラットフォーム（販売先／出品先でも可） / ステータス（在庫・販売中・売却済みのいずれかを入力） / 商品種別 / ASIN / 検品 / 仕入日 / 仕入額（原価でも可） / 仕入送料 / 仕入Pt払い額 / 仕入獲得ポイント / 想定販路 / 想定販売価格 / 手数料率 / 想定送料 / その他手数料 / 販売開始日（出品日でも可） / 販売日（売却日でも可） / 販売額（売価でも可） / 入金額 / 販売数 / 手数料（想定手数料でも可） / 送料（自己払い送料でも可） / 獲得ポイント（P払い額／Pt払い額／ポイントでも可） / SKU / 処分 / メモ（詳細／備考でも可）。
「商品名」列以外は無くても構いません。上の「上書きする」にチェックを入れずに取り込んだ場合、データは既存のデータに追加されます（重複チェックはされません）。チェックを入れると、商品名・店名・仕入日・仕入額が同じ既存の商品を新規追加せずに更新します（同じ内容の商品が複数ある場合は先頭から順に1件ずつ対応づけます）。
※以前は「販売開始日」「出品日」の見出しも売上日（販売日）として取り込んでいましたが、実際の出品開始日を記録できるよう、今回から専用の列として分けました。以前これらの見出しで売上日を管理していた場合は「販売日」に見出しを変更してください。

データのエクスポート／インポート

全データはブラウザの localStorage にのみ保存されます。他の端末に移す場合や、バックアップを取る場合は JSON ファイルとして書き出してください。
